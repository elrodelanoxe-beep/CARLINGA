# Carlinga v1.0

Juego de plataformas retro de 8 bits. Carla recorre la ciudad y La Mancha para rescatar a su mamá del monstruo Grumo en el colegio San Gabriel.

## Cómo jugar en el iPhone a pantalla completa

1. Abre la web del juego en Safari.
2. Pulsa Compartir y luego **Añadir a pantalla de inicio**.
3. Abre Carlinga desde el icono y gira el móvil en horizontal.

Desde el icono se abre sin barras del navegador y ocupa toda la pantalla.

## Controles

- Cruceta: moverse
- B: correr y usar el poder (mantener para disparar seguido)
- A: saltar (mantener para volar con el poder de vuelo)
- START: pausa · SELECT: sonido

Teclado: flechas, Z (A), X (B), Enter (START), M (SELECT).
